# 01 参考清单输入身份

状态：已完成实现与自动化验证；用户允许继续，并授权可交付时自主提交。Session：7.4。

问题：`ReferenceParser` 以路径字符串作为读取约定；网络调用把完整包降为 URL，再通过 `Single` 反查。当不同包指向同一 URL 时会失败，尽管官方目录只要求包标识唯一。

处理：使用现有 `ReferenceInput` 穿过解析器，两个实际读取方式分别读取路径与原始包，保留顺序、进度、增量合并、失败弃批和取消检查。输入定义移至独立 `desktop/ReferenceInput.cs`，不再藏在表格控件文件末尾；字段不变。

验证：增加真实 GUI 调用入口的多包回归，覆盖不同 URL 及同 URL；保留默认不选、逐包读取、合并去重、选择变化失效。运行桌面与核心／CLI 常规离线测试，显式联网／真实目录诊断不运行。

## 验证结果

- 修复前新增两项回归：不同 URL 通过；共用 URL 失败，预期总请求 4，实际 2，确认查询后未开始读取包。
- 修复后桌面总计 117，116 通过、1 项显式真实目录诊断未运行；核心／CLI 总计 290，284 通过、6 项显式联网／诊断未运行。两套错误、失败、跳过均为 0。
- 既有解析顺序、并行上限、默认单线程、取消收尾、重试、失败弃批与界面测试全部保留并通过。未运行真实官方请求或人工视觉验收。
- 自查改动仅涉及输入定义、解析器与两处调用、对应测试及任务记录；没有引入框架、依赖、配置项、文本或 UI 变化。
