# 01：固定业务数据外置

状态：网络入口 URL／launcher_id／名称／兼容入口默认 biz 已迁移至 config/network-services.json；其他固定业务数据后续按需统一盘点，不宣称全项目已完成。

## 用户要求

把 URL、游戏类型、官服／国际服等候选列表及其他自定义固定业务数据移至项目内、代码外的配置文件。代码负责逻辑，业务数据不继续散落在实现中。

补充确认：launcher_id 与 URL 同属入口配置；用户明确纠正后，本轮已一并外置。CDN 来自官方响应，不维护配置名单，不因新游戏出现再新增特例。默认包选择仅旧 CLI 契约仍保留，GUI 全部默认不选。

## 后续边界

- 开始时统一盘点相关数据，确定配置格式、加载入口和校验方式，不在当前网络请求优化中零散迁移。
- 配置外置不能取消官方来源限制、HTTPS 验证或把来自网络的不可信 URL 直接视为可信来源；具体安全边界需要届时明确。
- 本轮选用现有 System.Text.Json 读取项目 JSON，无新依赖；配置随构建／发布复制，缺失或无效明确失败，无硬编码回退。仍未改变安装和发布渠道。
