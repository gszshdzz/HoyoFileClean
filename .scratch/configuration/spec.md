# 集中化维护与结构分离

用户已批准实施（session 7.3）。配置面向维护者编译前维护，不新增终端用户设置；目标为集中化、灵活化、易适配易兼容。

用户后续明确：结构性内容由 agent 自行验证，连续完成以下全部模块，不逐模块等待；完成后提供统一改动列表和用户可操作验收步骤。

不改平台／格式安全规则，不迁移无关测试样例，不更改构建目标和依赖版本，不将官方返回未知算法或格式当成已支持。
