## 本轮要求与决定

- 本地／手动共用带复选框的表格；移除完整路径显示，修改时间到小时，文件名与大小变窄，大小以 KB 显示；新增状态、游戏、版本、条目数，游戏／版本先占位。
- 本地增加解析按钮，只解析勾选项；失败或同侧冲突不发布有效参考，单行成功仍明确显示成功。勾选变化使相关下游失效。
- 手动页跳过导入 JSON 在 manifest 操作上方，不要求先导入 manifest；移除旧列表和结果输出框，改同一表格；命令输出框改简短状态标签。
- GUI 所有中间 JSON 自动保存至程序本身目录的 `.temp` 子目录，不是当前工作目录、不向配置目录落缓存、不弹导出位置选择。CLI 不改。
- `.temp` 内容全部视为不可信可丢弃；每次运行／操作使用新子目录，不读取复用旧文件，不自动递归删除，路径含链接拒绝写入，权限问题不回退其他目录。核心安全写出和扫描根目录外输出规则保留。

## 验证

- 新增检查：本地与手动只解析勾选文件，表格状态／条目数更新，勾选变化失效，原始 manifest 字节保持不变；失败不启用结果；UTC 排序、本地显示到小时；JSON 同侧冲突拦截。
- 临时工作区检查：独立路径、旧内容不复用、固定类别路径、链接拒绝且外部目录不写入；测试路径注入批准临时根目录，测试不在实际程序旁写临时结果。
- 用户授权终止旧 GUI 锁文件进程后重新构建。最终桌面 36 项、核心／CLI 156 项全部通过，合计 192 项，Errors／Failed／Skipped／Not Run 均为 0；桌面构建 0 警告、0 错误。
- Standards review 发现系统异常原文展示；Spec review 发现手动批量添加延迟枚举的部分失败可能保留旧参考。分别改为 GUI 类型映射与完整枚举后更新表格，新增精确回归测试，局部复核确认修正且无明显回归。
- 扫描临时输出在创建目录前检查是否位于扫描根内；拒绝时不创建 `.temp`，避免检查失败前先污染扫描目录。
- 实际界面外观交用户验收，不依据离屏截图反复调整。
