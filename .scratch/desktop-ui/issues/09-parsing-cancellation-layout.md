## 用户反馈与范围

- 用户确认表格性能可以，本轮不继续扩大性能优化。
- 分组色稍加深，不写死 RGB，为深色模式留空间。
- 重复解析时直接丢弃旧结果；增加多线程清单解析和取消按钮。
- 快速横向缩放时提示文字换行与表格退让偶发不一致，需要根因修复。
- 不修改扫描并行／取消策略、CLI 输出，不增加主题系统。

## 实现

- 分组背景从当前单元格背景色／文字色按 9:1 混合，高对比度禁用；浅色、深色配色计算均有测试。
- ReferenceParser 单独负责 GUI 批次执行，最多 2 个文件并行（单核为 1），结果依输入顺序归位。逐文件异常只留摘要，整批成功且无同侧冲突才发布。
- 开始解析先清空旧参考、比较、选择与差异树及摘要；完成／失败／取消统一清空逐文件快照数组，无历史批次缓存，不调用 GC.Collect 管理程序内存。
- 底部取消按钮不在被锁定的页面内，仅解析时出现。取消后不发布任何批次结果，等待工作线程退出后恢复输入和重试；不强杀线程。读取／解压块、条目校验和合并检查 token；第三方单次解码与同步读调用需等返回。
- 修复前快速宽窄切换复现 labelBottom=184、inputHeight=170。移除 Note 的 SizeChanged 手动宽度回调；提示区、表格共用 TableLayoutPanel 的 AutoSize／Percent 两行，由布局测量文字换行，修复后 240 次切换检查通过。
