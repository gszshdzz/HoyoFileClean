# 桌面 UI：原生四步向导

基线：`52690574a21379c6fdf535d01e8d6a9a25659a2e`。本模块由用户在会话中明确指定，替代项目先前“界面尚未开始”的阶段状态；完成后等待用户验收，不自动提交、推送或开始下一模块。

## 已确认范围

- Windows Forms 原生标准控件；顶部总体流程、每次一步、底部按钮，可返回。不要自绘、皮肤、主题依赖、插件架构、通用向导框架或缓存。
- 真实接通 manifest 转换、轻／MD5 重扫、多输入对称比较；保留 CLI 与安全校验。两侧差异正常输出，同侧矛盾报输入错误。
- 第一步手动多 manifest、未压缩选项；解析即转换；跳过导入现成参考 JSON。显示来源、数量、大小、哈希，不猜游戏／包身份。
- 第二步明确指定目录，默认轻扫，自定义排除目录／文件；跳过导入扫描 JSON；显示模式、根目录、范围和链接警告。
- 第三步展示两侧摘要，A 游戏、B 参考；比较后显示游戏独有、参考独有、共有不同、未扫描范围。轻扫无 MD5 正常，不宣称内容一致。跳过导入报告，必须核对身份，不信任报告路径。
- 第四步左右标准目录树，可折叠和筛选；仅游戏侧已扫描范围内的实际文件可选。显示数量和总大小；选择集合任何变化自动取消确认，无选择或未确认时禁用演示删除。二次提示和结束提示明确未删除文件，不伪造成功。
- 上游输入／选项变化使相关下游结果、选择与确认失效；操作异步、禁止重复启动与错误推进，失败明确显示。
- 不实现自动获取、游戏／包识别、移动或真实删除。`safedelete` 是 agent 删除约束，不禁止未来应用功能；本模块仍无真实删除。
- 用户补充确认：CLI 和 GUI 分别直接调用内部模块；GUI 不通过 CLI，不解析其可读输出。保持分层清楚，避免堆积补丁。

## 最小实现决定

- 新增核心库，移动既有转换、扫描、比较、安全校验和 JSON 写出实现；CLI 保留原名称和命令，GUI 直接引用核心库。
- 暴露现有比较模块的经过校验的只读清单快照和详细结果，保留 CLI 的文件写出接口及原 JSON 格式，不新增组合模块或中间格式。
- 转换选输出目录，每份为原文件名加 `.json`；扫描与比较选新输出文件。拒绝覆盖，扫描输出仍必须在游戏根目录之外。批量部分失败时保留且列明已生成文件，不启用整批结果。
- 游戏导入要求一份带扫描信息的清单，记录根目录必须与用户明确指定的完整目录一致；不自动采用记录路径。
- 旧比较报告仅记录输入路径，无内容指纹；导入需核对当前两侧输入身份并重新计算、核对内容。返回重新计算的结果，不使用报告中的任意路径进行文件操作。
- 已载入清单作为本次快照；历史扫描不证明当前磁盘状态。滤掉的选择被移除并取消确认。目录与未扫描范围不可选择。
- 忙碌期间不能关闭，等待操作结束；不扩展现有扫描模块的取消能力。

## 验证与交付

构建 CLI、桌面及测试项目；重跑原 120 项与新增测试；做 Standards／Spec 双轴 code-review。自动测试覆盖共用读取／报告内容与身份校验、失效依赖、忙碌与失败恢复、选择与确认、真实转换→扫描→比较、原生树事件和四步最小窗口布局。

人工验收步骤见根目录 README；没有执行的文件对话框、演示弹窗或真实游戏目录验证必须明确列为未验证。任务记录见 `issues/01-desktop-ui.md`。
