# 模块 1：本地目录只读扫描

## 用户目标

输入扫描根路径和需要排除的文件夹、文件，不把排除项写死到代码，以便其他自定义用途；输出形式与解码的 manifest 类似。不跟随软链接，跳过时有适当提示。保持代码简洁，优先调用现成库。

用户追加批准：清理是主要用途，内容校验是次要可选能力。默认轻扫只读取路径与大小，不计算哈希、不显示过程进度；重扫先轻扫，然后复用已经得到的文件列表和总大小计算哈希，低频刷新同一行进度。排除选项一次可跟多个路径，并兼容原来的重复选项写法。

## 实施范围

本模块只读普通文件并输出本地文件清单，使用 .NET 自带的遍历和流式 MD5，不新增依赖。保留模块 0 的转换行为；比对、移动、界面、联网获取、并发和缓存不在范围内。

命令、排除路径匹配、JSON 字段和安全/失败行为的统一说明见 [README](../../README.md)。扫描清单覆盖选定范围，不作为可移动文件判断或完整游戏安装证明。
