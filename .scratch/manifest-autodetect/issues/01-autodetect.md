# manifest 自动识别

Blocked by: none
基线：`c171cdb`。状态：实现、测试与复核完成；未提交。

## 用户决定

程序自行识别压缩情况，不向用户暴露格式选择。移除旧参数，不考虑兼容；GUI 暂缓，仅移除失效的选项与更新调用。

## 实现

- 核心入口只接收输入与输出路径。读取至多四字节并复位：普通 zstd 头或标准可跳过帧头走现有解压库，否则直接走 protobuf 解析。
- 不以 `0A` 识别 protobuf，不手写帧解析，不在解压失败后尝试另一条路线。两路复用现有条目、MD5、路径与大小校验及安全写出。
- 保留压缩输入 64 MiB、解码内容 128 MiB 限制；CLI 移除旧参数和格式术语提示，损坏输入给出统一可读说明。错误仍通过核心结构化代码返回。
