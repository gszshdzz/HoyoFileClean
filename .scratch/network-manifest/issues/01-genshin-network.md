# 01：原神网络清单核心逻辑

状态：实现与自动验证完成；用户追加 CLI／GUI 后授权审查修复并提交，已纳入本次交付。最终结果见 [REVIEW.md](../REVIEW.md)。

## 改动

- 官方两服当前版本与本体／语音目录查询，资源包按份获取。
- 有界下载、官方域名限制、禁用重定向、取消与超时。
- 解压长度与 MD5 校验复用现有流，现有条目与合并规则不另写。
- 内存来源支持真实 URL，本地来源仍使用完整磁盘路径。
- 不增加依赖、缓存、CLI 或 GUI；其他渠道未确认，其他游戏与预下载暂缓。
