# 02：网络转换 CLI 与参考页 GUI

状态：实现与自动验证完成，用户授权审查修复后提交，已纳入本次交付；实际桌面视觉验收仍由用户完成。最终结果见 [REVIEW.md](../REVIEW.md)。

## 用户补充与交付

- CLI 不新增独立命令，以 `convert --network` 接入；游戏、区服、版本必填。默认本体，可重复 `--package` 选择语音包。
- GUI 来源下方并排三列单选游戏／区服／版本；版本为最新版或自定义版本输入框，不枚举旧版。
- “查询／获取／解析”与共用表格分工明确：查询才联网填区服，获取整批下载后填表及游戏／版本，勾选后离线解析；启动和切换不联网。游戏列显示“原神-官服／原神-国际服”，无本地修改时间显示“—”。
- 复用核心下载、解析与安全写出，GUI 复用 ReferenceParser、ManifestTable 和向导失效／忙碌规则；不加依赖，不写磁盘缓存。
- 指定版本原值请求、严格核对官方返回；不存在或不符不退回最新版。

## 验证

- 核心常规 Total 210，Errors 0，Failed 0，Skipped 0，Not Run 2，即 208 项通过。两项显式联网默认不执行。
- 桌面常规 Total 75，Errors 0，Failed 0，Skipped 0，Not Run 1，即 74 项通过。未运行项为既有真实样本诊断。
- 真实官方两服 `7.1.0`：各本体 2,744 个文件，下载、长度、MD5 与解析成功。
- 最终构建零警告、零错误；使用 `-explicit only -class HoyoFileClean.Tests.NetworkManifestTests` 复跑两项官方联网测试，两服最新版全部十份清单及两服旧版本本体共十二份均通过。该运行器显示 Total 32、Not Run 30，是同类的三十项非显式用例在 only 模式下未执行；它们已经在常规回归中通过，不能解读为联网漏测。
- 真实 CLI：国服 `latest` 默认本体 2,795 个文件、135,833,870,380 字节；国际服 `7.1.0` 显式本体＋中文语音 2,921 个文件、146,077,252,038 字节。输出位于批准的临时目录，不写游戏目录。
- 离线测试含网络参数缺失／重复／非法、拒绝覆盖、本体默认值与选包输出、自定义版本不回退、界面显式查询／获取／解析、选项失效、失败清空及最小尺寸边界。
- 新桌面测试起初在普通同步上下文中运行，异步界面回填竞态；改为真实 `Application.Run` 消息循环后同一完整流程通过。未修改生产任务调度来绕过测试。版本输入框的实际可见性、尺寸和父容器边界有断言；离屏位图未完整呈现原生输入框，不当作完整视觉验收。
- 一轮并行构建与联网测试占用同一 DLL，报 MSB3027／MSB3021；改为先完成构建再运行同一输出目录的测试，重新回归通过。未跳过失败检查。

## 用户验收

运行桌面程序，确认打开网络页不请求服务器；选原神→查询→官服／国际服→最新版或自定义 `7.1.0`→获取，检查游戏／版本列；勾选本体或语音→解析，成功后可下一步。返回改区服／版本应清空旧表与参考，再次获取失败不得使用旧结果。CLI 示例见 README。
