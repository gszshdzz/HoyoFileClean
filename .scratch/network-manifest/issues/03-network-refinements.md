## 用户要求与修改

- 网络游戏／区服只显示六行高度，数据不截断，更多项目可纵向滚动；按原生控件完成 DPI／字体初始化后的实际行高和边框计算。测试放入二十一个项目并滚动到第十六项，仍保留全部项目。
- 本地与手动和网络一致：无勾选项时禁用解析。共用表格批量添加／删除后通知选择状态刷新，防止按钮卡在旧状态。
- CLI 主帮助只用通用占位，具体游戏／区服／资源包名放在下方提示示例。去掉解析阶段的固定名单，游戏／区服依据官方 `game.biz` 的最后一个下划线分段匹配，资源包依据构建 `matching_field`。标识不存在在查询后返回业务错误，不假装参数格式错误。原神示例改为官方 `hk4e/cn`，不保留自定 `genshin/china` 别名。
- GUI 查询复用分支目录接口，不再为了列区服额外请求构建目录，两服务共两次请求。
- 官方服务入口和清单 CDN 限制保留；允许未来标识通过参数层不等于已适配其他游戏清单格式，不扩大“只连接官方”的边界。

## 首次慢的证据与修复

显式 `NetworkTimingTests` 只连接官方服务器，记录连接事件与耗时，不打印完整 URL／查询凭据。

1. 基线：首次元数据约 0.63 秒；首次 CDN 响应头约 21.1 秒，之后请求数毫秒。IPv4／IPv6 分别连接官方 CDN 均可快速返回，不能据此禁用 IPv6。
2. 连接事件：DNS 数毫秒完成，首个 CDN IPv4 地址的 TCP 在约 21 秒后失败，第二地址几毫秒成功，随后 TLS 很快完成。可重复，不是解析或界面问题。
3. `OfficialConnection` 使用 .NET DNS／Socket，在每个 DNS 地址上最多等待两秒；连接失败或该地址超时才继续下一个，外部取消立即停止。TLS、代理和连接池仍归 .NET，无自定义 HTTP、IP 固定、协议禁用、系统设置修改、预联网或下载重试。
4. 同轮对照：旧连接首批五份 21.484 秒，修复后同首个坏地址 2.238 秒；第二轮分别 0.180／0.153 秒。只描述当时测量，不承诺所有网络时延。
