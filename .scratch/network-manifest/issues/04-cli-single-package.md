# 04：CLI 每次最多选择一个资源包

状态：实现及自动验证完成，用户授权审查修复后提交，已纳入本次交付。最终结果见 [REVIEW.md](../REVIEW.md)。

用户反馈重复 `--package game --package gamwe` 未被参数层拒绝，后续出现通用读写错误。最新约定：CLI 每次最多一个包，覆盖此前允许重复选包的设计；不改 GUI 多选或核心多输入能力。

- CLI 参数对象只保存单个可选 `Package`，不再积累列表；复用必选项同样的重复键拒绝规则。
- 不指定时默认本体，指定一次仍依据官方响应判断包是否存在，未知包不使用固定名单提前拦截。
- 重复同值或不同值均先返回退出码 `2`，标准错误提示 `--package 最多指定一次，每次网络转换只能选择一个资源包。`；不创建客户端、不联网、不进入文件操作。
- 帮助与 README 去除重复选包和多包示例，主用法仍为通用占位。

验证：先运行两项回归，旧实现均错误返回 `1`；修复后全部核心／CLI 常规测试 Total 220、Errors 0、Failed 0、Skipped 0、Not Run 4，即 216 项通过。未运行项是四项既有显式联网测试。本轮没有联网，也未触碰 GUI。使用已有输出证明数量错误在输出检查之前发生，且文件原文保持不变。

本次只修复重复包参数的入口限制，不声称已复现或定位单包请求下可能发生的底层 IO 异常。
