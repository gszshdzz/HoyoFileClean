# 08：区服版本发现与网络取消退出

状态：按用户确认完成实现，专项和核心回归通过；桌面完整回归仍有布局失败，待实际验收，未提交。

后续职责调整已由 [11](11-explicit-three-stage-network-ui.md) 取代：区服入口在前，每次查询仅请求所选服务；三个按钮分别查询游戏、查询 manifest 目录、获取勾选包并解析。本记录保留当时验证结果。

## 用户确认的职责

- 查询：根据游戏查询可用服务器及当前版本。实测官方分支接口已提供 `game.biz` 与 `main.tag`，不需要构建目录。保留两个按钮。
- 获取：根据游戏、区服、版本请求构建目录并下载 manifest 正文。解析仍离线。
- 网络下载卡住时必须可取消或退出。
- 国际服偶发低速原因未定，暂缓处理并记录，见任务 09。

## 实现

- 核心新增 `GetGameVersionsAsync(service, game, token)`，只读取分支，返回所选游戏的区服与版本；分支 JSON 克隆至内存供后续获取使用，不输出凭据或完整 URL。
- `GetCatalogAsync(RemoteGameVersion, ...)` 使用查询保留的分支信息，只请求构建目录；复用原有版本和 CDN 安全校验。旧核心入口及 CLI 行为不变。
- 桌面查询两个已知服务以发现区服，区服列表来自官方返回；只查询所选游戏，不为其他游戏请求构建信息。单服务失败可保留另一服务实际发现的结果，不自动代替用户选择后的获取。
- 当前版本显示在版本选项与底部状态；自定义版本手填，不枚举历史。切换区服或版本清空下载结果但保留发现结果，更换游戏或重查清空发现结果。最新版以本次查询为准，刷新需重新查询。
- 取消沿用底部按钮位置，网络期间显示“取消网络操作”。查询／构建请求／正文读取均传递同一操作取消令牌，取消不发布本批结果，可再次操作。
- 网络期间允许关闭按钮及窗口关闭；先取消网络操作，待资源收尾后自动关闭。根因原为桌面未传取消令牌，同时禁用关闭并拦截 FormClosing。扫描与解析原有关闭行为不在本轮扩大修改。
