# 09：国际服下载偶发低速

状态：用户要求暂缓，原因未确定，不实施优化。

## 已知观察

- 用户报告同一国际服下载有概率约 500 kbps、耗时十余秒，随后一次超过 100 Mbps、很快完成；速度单位按用户原描述保留，不擅自换算。
- 本会话多轮国际服获取总耗时显著波动；任务 08 的真实请求为约 8.61 秒，其中构建请求约 1.20 秒。
- TCP 连通、TLS／API 响应和下载吞吐量是不同阶段；先建连成功不代表该连接的持续传输速度最快。现有证据不足以区分节点、出口、代理路径或链路拥塞等原因。

## 后续边界

仅在用户重新指定后调查。针对同一次慢／快操作采集分段耗时与实际路径，注意不输出请求凭据。不凭概率波动添加 IP 黑名单、运营商规则、下载并发、测速选路或自动重试，不放宽 TLS 验证。
