状态：实现、专项及核心验证完成，待用户验收，未提交；桌面布局回归仍未全绿。

## 根因与用户原则

- 网络表格曾按 MatchingField == game 默认勾选，与用户明确选择相违背。
- 非原神目录失败是核心仅允许原神两个 CDN 的遗留限制，不是 game 字段勾选导致，也不能由网络失败推断本地解析格式不支持。
- 用户澄清“只连接官方”意为不依赖第三方维护的数据服务，而不是按游戏限制官方返回资源地址。程序保持通用逻辑，固定业务数据与代码严格分离，动态数据直接使用官方响应。
- 用户选择信任官方构建响应的具体 URL，接受取消独立固定 CDN 名单带来的信任边界变化；保留 HTTPS／默认端口、禁止重定向、大小／MD5／格式等通用校验。长期规则已写入 AGENTS.md。

## 修改

- 网络列表全部默认不选，未勾选时获取解析禁用；不识别 game、语言或游戏名来替用户选包。既有 CLI 默认本体契约未在 GUI 任务中改动。
- 共用列权重为 10／7／4／3／4／3／3／3，顺序不变。
- config/network-services.json 保存服务标识、显示名称、分支 URL（含 launcher_id）、构建 URL、兼容入口默认 biz。core/NetworkService.cs 通用加载校验，随核心项目引用传递至应用与测试输出，发布同样复制；无依赖增加、无内置回退。
- 官方构建响应创建的 RemoteManifest 保留其 URL 来源标记，不按 CDN 域名分类。替换 URL 或手工构造对象不能联网下载；静态 Read 离线解析不要求来源标记。官方 API 响应若被攻击或错误返回地址，不再另有域名名单防护。
- 明确元数据和清单格式检查仍可拒绝不支持内容，不承诺所有游戏、所有资源包均已验证，不添加逐游戏解析实现。
