# 14：双地址族独立递增连接

状态：实现、核心常规及真实两服查询复验完成；未提交，待用户验收。

## 用户最终策略

- DNS IPv4、IPv6 候选各自按原顺序去重，初始各连一个；单栈只启动一个，不判断网卡／网络环境，没有候选则不启动。
- 每 0.5 秒每族各新增一个未尝试地址，每次尝试最多 1.5 秒。立即失败也不额外加速分派，仍按节拍尝试余下地址。
- 首个 TCP 成功后取消其余尝试，收尾并释放未采用的流；全部失败正常报错，用户取消停止后续分派。
- 用户明确撤回额外每族／总并发上限要求：节拍与超时自然约束，允许边界时短暂重叠，不增加计数限流逻辑。
- 取代任务 13 的最多两路／不同前缀策略，不按地区、游戏、网段或协议可达性写例外。
