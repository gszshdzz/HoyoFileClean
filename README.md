# HoyoFileClean

对照游戏版本清单，检查本地文件的路径、大小及可选 MD5 差异。提供 Windows 桌面向导和命令行工具。

**第五步会实际处理明确勾选的游戏侧文件**，支持系统回收站、永久删除和保留目录结构的移动。清单外不等于无用，请先关闭游戏与更新器，优先选择可恢复的操作。

## 快速开始

需要 Windows 和 .NET 10 SDK，在项目根目录执行：

```powershell
dotnet run --project desktop\HoyoFileClean.Desktop.csproj
```

首次构建会获取项目声明的 NuGet 依赖，已缓存时可加 `--no-restore`。

桌面按五步操作：

1. **游戏读取**：选择目录，读取游戏并加载预置排除，再轻扫或计算 MD5；也可导入历史扫描 JSON。
2. **参考清单**：自动匹配官方清单、手动网络选包，或读取本地 manifest／本项目 JSON。
3. **确认与比较**：核对双方身份、包体及扫描范围，再比较。
4. **结果与选择**：筛选差异、展开目录并勾选游戏侧文件。
5. **文件操作**：核对选择并确认，预检后实际处理；查看每项成功／失败／未处理结果。

启动和切换来源不会自动联网，网络请求须点击按钮触发。详细操作见 [使用指南](docs/usage.md)。

## 命令行

在项目根目录执行，示例路径需自行替换：

```powershell
dotnet run -- convert "manifest路径" "参考清单.json"
dotnet run -- scan "游戏目录" "游戏目录之外的扫描.json"
dotnet run -- compare "比较结果.json" --a "扫描.json" --b "参考清单.json"
```

扫描加入 `--hash` 才计算 MD5；`--a`、`--b` 均可提供多份清单。网络转换、排除规则和退出码见 [命令行说明](docs/cli.md)。

## 如何理解结果

- 清单外文件不等于垃圾；一份清单可能只覆盖一个资源包。
- 轻扫只比较路径和大小，不能证明文件内容一致；双方都有 MD5 才比较哈希。
- 排除或跳过链接的范围单独列为“未扫描范围”，不能认定缺失或独有。
- 输入只读；显式导出和 CLI 输出拒绝覆盖已有文件，输出父目录须存在。
- 已验证样本不代表所有游戏、渠道和版本都受支持；历史扫描不证明当前磁盘状态。
