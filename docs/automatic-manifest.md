# 自动获取 manifest

Session 18。参考清单的第一项、默认项为“自动获取”，原“网络获取”更名“网络选择”。共用网络页面，自动方式隐藏区服／游戏／版本选择及前两个按钮，改为只读文字展示当前识别的游戏、版本和需求包体；保留“获取 manifest 并解析”及原网络取消操作。

游戏识别结果的完整 `biz`、三段 `version`、多值 `package` 用于精确匹配官方响应。查询现有配置中的官方服务，确认完整 biz 的分支唯一，再按识别版本取得全部 manifest；需求包全部存在才下载、解析并合并。表格显示全部候选，需求包自动勾选，复选框灰色且不可编辑，未选包保持未获取。沿用现有下载校验、解析、取消和失败处理，不新增库、缓存或并发。两份识别配置仍独立，不按检测 ID 关联。

信息不足、不唯一、需求包缺失或任一服务查询失败均停止，不用其他游戏、版本或部分包替代。可切换网络选择手动查询。切入／离开自动方式清空网络行，防止沿用手动勾选或旧游戏结果。

`config/AutomaticManifestRules.cs` 的 `IncompleteGames` 是编译期可配置的自动获取禁用名单，按游戏识别结果的 `game` 或完整 `biz` 原值匹配。当前包含绝区零及崩坏三的游戏族和国服／国际服标识；命中后自动获取选项禁用，默认转为网络选择，其余方式不受影响。规则完善后从名单移除并重新构建。仅有 biz 的历史扫描同样受限制；不通过拆分 biz 推测游戏族。游戏识别、扫描排除和自动获取限制分别维护，禁用名单不改变识别输出。
