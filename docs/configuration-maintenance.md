## 维护入口

| 内容 | 文件 | 说明 |
| --- | --- | --- |
| 服务配置 | `config/network-services.json` | Id、NameTextId、BranchUrl、BuildUrl、LauncherId；Id 唯一，URL 无预设查询串，无默认游戏／包。 |
| 编译前策略 | `config/Maintenance.cs` | 默认目录、大小、超时、连接节拍、线程数、刷新和缓冲；修改后重新构建。 |
| 官方请求／响应 | `core/Models/OfficialProtocol.cs` | 字段映射、数值和请求参数集中；改名不等于支持新格式或算法。 |
| 网络结果 | `core/Models/NetworkModels.cs` | 原始身份和可信下载来源标记。 |
| 持久化文件结构 | `core/Models/FileDocuments.cs` | 清单、报告、排除规则及模式标记，读取／写出共用。 |
| protobuf | `Protos/Sophon.proto` | 保留协议来源和编号。 |
| 展示文字 | `presentation/Languages/zh-CN.json` | 调用处直接使用字符串 ID，例如 `L.Get("ComparisonResultHeading")`；没有手工 ID 枚举或第三份清单。 |
| 默认语言 | `config/PresentationOptions.cs` | 独立的编译前配置，只定义默认值，不包含加载逻辑。 |

语言文件编译嵌入程序，不开放运行时编辑设置；按当前界面语言查找，缺少翻译回退中文。目前只有简体中文资源，未新增切换控件，不宣称其他语言已翻译。官方标识、文件名、用户路径原样展示；Windows 自带按钮／对话框语言由系统管理。
