## 文件操作安全差异审查

高风险路径采用重点分析：正式入口只有一处 `OperationConfirmed` 订阅，调用一处 `ExecuteFileOperationAsync`，后者只有一处执行器调用；执行器移动／回收各一个生产调用点，永久删除另由跨卷复制核验后复用。CLI、核心转换、扫描与比较不新增执行入口。

基线仅有确认事件，无实际文件处理。新增执行复用 `WizardSession.ValidateGameInput`、`FilePathRules` 及扫描范围；未移除既有路径校验或默认拒绝。威胁模型为不可信相对路径、扫描后文件变化、链接替换、目标冲突和普通程序占用，不包含已明确排除的同权限恶意瞬时重解析点篡改。

追踪及隔离测试涵盖：路径越界／别名、重复、未扫描范围、已有重解析点、源目标包含关系、整批预检、逐项身份／大小／已有 MD5 复核、不覆盖、占用拒绝、部分成功后停止、未选文件正文不变。跨卷引擎复制成功并核验 SHA256 后才删除源。回收通过 Shell，检查回收标志和回调结果，不显式降级永久删除。参考 Microsoft Win32 官方 `IFileOperation::SetOperationFlags`、`IFileOperationProgressSink::PreDeleteItem` 及 `TRANSFER_SOURCE_FLAGS` 文档核对相关契约。

未确认新增越界、覆盖或误删漏洞；该结论不等于所有 Windows 环境均已验证。整体属于高风险能力，未进行覆盖率测量或变异测试。需求轴指出“部分失败后界面失效”缺少贯通用例，目前由执行器部分失败测试和界面成功／预检失败测试分别支撑，静态调用链包含相应失效分支，未将此缺口称为实现错误。
