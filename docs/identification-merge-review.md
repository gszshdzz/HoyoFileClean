## 总体差异

- 向导先识别并扫描游戏，再获取参考清单；识别或扫描失败、取消后不发布结果，允许重试。
- 游戏结果紧凑显示完整游戏标识、版本、渠道及动态插件；扫描 JSON 可携带识别记录，旧 JSON 兼容，导入不访问原游戏目录。
- manifest 使用 20 条编译期规则识别游戏族、确定的完整标识和资源包；未知不猜、冲突保留证据，不改变文件比较规则。
- 三种参考来源均可双击成功行查看已载入快照、文件列表并导出单条 JSON；不重读源文件、不重新联网、拒绝覆盖。
- 网络入口、游戏规则和 manifest 规则都在 `config/` 维护并编译，不增加依赖或旁置配置。
