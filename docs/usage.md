# 桌面使用指南

从项目根目录启动：

```powershell
dotnet run --project desktop\HoyoFileClean.Desktop.csproj
```

当前为五步向导。所有游戏输入只读，最后一步尚不执行真实移动／删除；比较差异本身不证明文件可以清理。

## 1. 游戏读取

选择“扫描游戏”或“导入 JSON”，两种方式都须明确指定游戏根目录。

- **扫描游戏**：先点击“读取游戏并加载预置排除”，成功后才能正式扫描。预读取只探测配置候选和必要元信息，不建立全目录清单、不计算 MD5；正式扫描复用识别结果，不重新打开已排除的元信息文件。元信息变更后需重新读取。
- **轻扫**只记录路径和大小；选择 MD5 重扫才读取文件正文。扫描时显示文件数／字节数进度；失败或取消不保留本次可用结果，收尾后可重试。
- **历史 JSON**：导入本项目扫描结果，校验记录根目录与指定目录一致；不重新扫描或识别，不证明当前磁盘状态。

排除目录和文件分别维护，支持添加、多选移除和同类多项拖入。规则使用根目录内的精确路径、不区分大小写、不支持通配符；排除目录包含全部子目录，不能排除根目录或根目录外路径。混合文件／目录或越界批次整批拒绝。

“导入规则”合并去重，失败保留原列表；“导出规则”保存当前列表（含预置），可再次导入，拒绝覆盖已有文件。格式见 [排除规则](cli.md#排除规则)。重新加载游戏或换目录移除自动添加的旧预置，保留手动规则；调整排除项或 MD5 选项无需重复预读取。

链接／Windows 重解析点不进入扫描，跳过范围会提示并记录；无法访问元数据时停止，不静默遗漏。当前预置中 `ldiff` 排除扫描；`pkg_version` 和 `Audio_Chinese_pkg_version` 正常扫描与比较。结果页隐藏是另一项规则，不等于扫描排除。

## 2. 参考清单

启动、切换来源或改选均不自动联网。仅处理勾选项，整批成功且无同侧文件矛盾才可下一步；单行成功不代表整批成功。

### 自动获取

默认来源。按已识别的完整 `biz`、三段版本和全部需求包体精确匹配官方响应；信息不足、身份不唯一或缺包即停止，不猜测或回退。表格显示全部候选，仅需求包勾选，复选框锁定。当前绝区零、崩坏三因包体识别不完备禁用自动获取，可用网络选择；详见 [自动获取规则](automatic-manifest.md)。

### 网络选择

1. 选择服务入口，点击“查询游戏列表”，只查询所选服务；游戏不默认选中。
2. 明确选择游戏及当前／自定义三段版本，点击“查询 manifest 列表”；取得全部包，默认均不选。
3. 勾选所需包，点击“获取 manifest 并解析”；只下载这些包，不重新查询分支或构建目录。

游戏显示官方原始 `biz`，重复标识附原始 `game.id` 区分，不猜渠道名称。版本不符不退回最新版，不枚举历史版本。改变游戏／版本清空旧包表与参考结果；换服务还清空游戏列表。重新查询或失败不沿用旧列表。已知入口不代表全部渠道，动态列出也不代表所有格式均已验证。

三个阶段都可用同行最右的“取消网络操作”；取消不发布部分参考结果。网络中关闭窗口会先取消并收尾，再关闭。

### 本地获取与手动输入

- **本地获取**：默认目录为 `%APPDATA%\miHoYo\HYP\1_1\modules\sophon\manifest`，可浏览、输入或拖入单个目录；点击获取只列当前目录普通文件元数据，不递归、不按扩展名过滤、不读链接文件。勾选后另点解析。改目录清空旧表，不自动获取。
- **手动输入**：添加或拖入一份／多份压缩 manifest、未压缩 manifest 或本项目 JSON，按内容识别。路径去重，新项默认勾选，不自动解析；含目录、缺失或元数据不可读项的批次整批拒绝，正文读取失败在解析阶段报告，不移动源文件。

默认本地按修改时间降序、手动按名称升序，可按列排序；表头可全选／清空，行高和表头高度不可拖动。未解析元信息留空，尝试后未知显示“—”；冲突可悬停查看证据。有 `biz` 显示 `biz`，否则显示 `game`，不猜版本或身份。包类型按已有格式／官方 branch 显示，不因显示“预下载”就新增网络预下载查询能力。

解析成功后双击非勾选列查看该条目详情，可导出独立 JSON；使用已载入快照，不重读输入、不重新联网、不导出整批合并结果。已有目标拒绝覆盖。成功行在整批失败时仍可查看，但不能推进；重试、切换来源或移除行使旧详情失效。

本地补丁清单仅提取目标文件，不证明完整覆盖或目标版本。包含已选有效补丁时，下一步弹出风险确认，默认“否”；返回后再次前进仍需确认。不要把旧版本引用当作目标版本。

## 3. 确认与比较

核对排除／跳过范围、游戏实际、manifest、输出摘要四栏。文件数与大小按各侧并集，MD5 显示已有数／总数；未知显示“—”，不是零。页内点击“比较”，成功才可下一步，不自动跳页，不提供报告导入。

同侧重复记录一致则去重、矛盾则失败；两侧之间大小或 MD5 不同是正常比较结果。双方都有 MD5 才比较哈希，其余只比较大小。对侧明确排除或跳过链接的路径归为“未扫描范围”，不能认定独有或缺失；轻扫未算 MD5 不属于此类。

## 4. 结果与选择

- 分类按钮可多选或全部关闭，默认显示除相同外的四类，数量在按钮内。
- 两侧共用行、滚动和目录折叠；箭头指向独有侧，`≠` 不同、`=` 相同、`—` 未扫描范围。独有紫字、不同红字；相同项悬停符号可区分 MD5 相同与仅大小相同。
- 仅已扫描的游戏侧文件可选；单文件、目录及左上表头支持勾选，目录范围包含折叠子文件。部分选中时点击补全，全选后点击清空；数量和大小即时更新。
- 关闭分类或重新隐藏文件，仅取消被隐藏项的选择。参考独有和未扫描项不可选。
- 已识别游戏默认隐藏预置结果项，当前四款仅为 `pkg_version`；“显示隐藏项”只影响本页，不改变扫描记录和比较计数。`Audio_Chinese_pkg_version` 正常显示，未知游戏不套预置。

## 5. 文件操作

查看所选文件的类别、大小、校验状态与完整路径，可切换回收站、永久删除或移动；移动需填完整目标路径。包含非游戏独有的文件时先额外提示风险，再进行操作确认，默认拒绝。

**这些只构成界面确认，目前没有连接真实文件处理，不会移动或删除，也不能当作清理成功。**

## 结果失效与限制

改变输入、路径或扫描选项会清空依赖结果和选择；参考输入变化不丢弃独立游戏扫描。操作期间锁定编辑和重复启动，列表仍可查看滚动。取消须等工作线程收尾，不保证即时停止，不使用失败批次的部分结果。

桌面结果只留内存，关闭后释放，不创建中间 JSON、`.temp` 或磁盘缓存；旧遗留目录不会自动清理。显式导出可能因写出／发布失败留下 `.partial`，但不覆盖已有目标、不作为成功结果。

实际系统对话框、资源管理器拖放、不同 DPI 和真实桌面绘制不能仅凭离屏测试视为验收通过。详情独立快照增加内存，真实大批成功清单峰值尚未重测；历史白块／闪白与拖动测量不能视为全部视觉问题已根治。
